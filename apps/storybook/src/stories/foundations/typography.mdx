# Typography

The package ships **Geist** (variable font, bundled through `@fontsource-variable/geist`) as `--font-sans`, and headings use `--font-heading`, which defaults to the same family. Sizes are Tailwind's scale; components use `text-sm` for most UI text and `text-xs` for secondary text.

</En>
<Es>

# Tipografía

El paquete incluye **Geist** (fuente variable, empaquetada con `@fontsource-variable/geist`) como `--font-sans`, y los títulos usan `--font-heading`, que por defecto es la misma familia. Los tamaños son la escala de Tailwind; los componentes usan `text-sm` para casi todo el texto de interfaz y `text-xs` para el secundario.

</Es>

<En>

| Utility     | Size      | Typical use                         |
| ----------- | --------- | ----------------------------------- |
| `text-xs`   | 0.75rem   | Descriptions, badges, shortcuts     |
| `text-sm`   | 0.875rem  | Buttons, inputs, menus, body of UI  |
| `text-base` | 1rem      | Long-form text                      |
| `text-lg`+  | 1.125rem+ | Headings                            |

## Change the font

```css
@import "@aureus-core/ui/styles.css";

@theme inline {
  --font-sans: "Inter Variable", sans-serif;
  --font-heading: "Fraunces Variable", serif;
}
```

Load the font yourself (for example with `@fontsource-variable/inter`).

</En>

## Cambia la fuente

```css
@import "@aureus-core/ui/styles.css";

@theme inline {
  --font-sans: "Inter Variable", sans-serif;
  --font-heading: "Fraunces Variable", serif;
}
```

Carga la fuente tú mismo (por ejemplo con `@fontsource-variable/inter`).
