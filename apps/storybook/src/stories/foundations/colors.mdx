export const pair = (name) => ({ [name]: `var(--${name})`, [`${name}-foreground`]: `var(--${name}-foreground)` });

<En>

# Colors

Semantic tokens: components ask for a *role* (`--primary`, `--muted`), never a raw color. The swatches read the live CSS variables, so switching the **theme** toolbar shows the dark values. Each surface token has a `-foreground` pair for the text on top of it; keep 4.5:1 between them.

</En>
<Es>

# Colores

Tokens semánticos: los componentes piden un *rol* (`--primary`, `--muted`), nunca un color concreto. Las muestras leen las variables CSS en vivo, así que al cambiar la barra de **tema** se ven los valores oscuros. Cada token de superficie tiene una pareja `-foreground` para el texto que va encima; mantén 4.5:1 entre ellas.

</Es>

## Using them

- In Tailwind classes: `bg-primary text-primary-foreground`, `border-border`, `text-muted-foreground`.
- In CSS: `color: var(--muted-foreground)`.
- To change them for your product, see [Theming](?path=/docs/guides-theming--docs).

</En>
