# Aureus Frontend Kit

**Aureus Frontend Kit** is the set of shared frontend resources of Aureus, published to npm under the `@aureus-core` scope. This site documents every package:

| Package | What it is | Sections |
| --- | --- | --- |
| `@aureus-core/ui` | The React component library: the full [shadcn/ui](https://ui.shadcn.com/) catalogue (62 components, radix-nova style) compiled, typed and verified, plus our own components. React 19 and Tailwind CSS v4. | **shadcn**, **components** |
| `@aureus-core/utils` | Framework-free utilities with no dependencies: the shared date-format catalog and the `display` functions that show values the same way in every app. | **utils** |

## How this site works

- **Toolbar 🌐**: switch the documentation between English and Spanish. Component demos stay in English.
- **Toolbar theme**: light and dark, using the same `.dark` class your app uses.
- **Toolbar ⇄**: left-to-right or right-to-left, with `dir` on `<html>` and the `DirectionProvider`.
- **Every utils page** explains a module, with live examples that follow the 🌐 toolbar.
- **Every component page** has the import line, when to use it, its anatomy, a Playground with controls, the API of each part, examples, keyboard and ARIA notes, and the theme tokens it uses.
- **Every story is a test**: it renders in Chromium, runs its interaction script and passes an axe accessibility check in CI.

## Where to go next

1. [Getting started](?path=/docs/guides-getting-started--docs): install the package and import the styles.
2. [Theming](?path=/docs/guides-theming--docs) and [Dark mode](?path=/docs/guides-dark-mode--docs): adapt the look to your product.
3. [Right-to-left](?path=/docs/guides-right-to-left--docs) and [Hooks & utilities](?path=/docs/guides-hooks-utilities--docs).
4. [Foundations](?path=/docs/foundations-colors--docs): the color, radius and typography tokens.
5. [Display](?path=/docs/utils-display--guide) and [Date formats](?path=/docs/utils-date-formats--guide): show values and dates the same way in every app.

# Aureus Frontend Kit

**Aureus Frontend Kit** es el conjunto de recursos frontend compartidos de Aureus, publicados en npm bajo el scope `@aureus-core`. Este sitio documenta todos los paquetes:

| Paquete | Qué es | Secciones |
| --- | --- | --- |
| `@aureus-core/ui` | La librería de componentes React: todo el catálogo de [shadcn/ui](https://ui.shadcn.com/) (62 componentes, estilo radix-nova) compilado, tipado y verificado, más nuestros propios componentes. React 19 y Tailwind CSS v4. | **shadcn**, **components** |
| `@aureus-core/utils` | Utilidades sin framework y sin dependencias: el catálogo compartido de formatos de fecha y las funciones `display`, que muestran los valores igual en todas las apps. | **utils** |

## Cómo funciona este sitio

- **Barra 🌐**: cambia la documentación entre inglés y español. Las demos de los componentes siguen en inglés.
- **Barra de tema**: claro y oscuro, con la misma clase `.dark` que usa tu app.
- **Barra ⇄**: de izquierda a derecha o de derecha a izquierda, con `dir` en `<html>` y el `DirectionProvider`.
- **Cada página de utils** explica un módulo, con ejemplos en vivo que siguen la barra 🌐.

- **Cada historia es un test**: se renderiza en Chromium, ejecuta su guion de interacción y pasa una revisión de accesibilidad con axe en CI.
