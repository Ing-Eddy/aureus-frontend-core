# Theming

Every color, radius, font and text size in the components comes from CSS custom properties (tokens). Change the tokens and every component follows; you never have to edit component code.

## Override tokens in your app

Add your values **after** the package import. Light values go on `:root`, dark values on `.dark`:

```css
@import "@aureus-core/ui/styles.css";

:root {
  --primary: oklch(0.55 0.2 260);
  --primary-foreground: oklch(0.98 0 0);
  --radius: 0.5rem;
}

.dark {
  --primary: oklch(0.72 0.15 260);
  --primary-foreground: oklch(0.15 0 0);
}
```

The tokens are listed, with live swatches, under [Foundations › Colors](?path=/docs/foundations-colors--docs). Check contrast when you change a pair (`--primary` / `--primary-foreground`, `--muted` / `--muted-foreground`…): text needs 4.5:1 for WCAG AA.

## Theme builder

Rather than writing the values by hand, open [Tools › Theme Builder](?path=/story/tools-theme-builder--default). Pick a primary color, a neutral palette and a radius, override any token, and watch the real components and the WCAG contrast of every text pair update live in light and dark mode. You can also paste a theme you already have (from ui.shadcn.com, tweakcn or an earlier export) to keep editing it.

- **Download .css** saves a standalone theme file (`:root`, `.dark` and `@theme inline`, all in OKLCH) for any Tailwind CSS v4 shadcn app. It contains no fonts or letter spacing: those come from the Typography Builder.
- **Copy** puts the same content on the clipboard.

The file is named `theme.css` by default. In an app built on this package, import it after `@import "@aureus-core/ui/styles.css"` (it sets every token in its light and dark blocks, so it replaces the Aureus brand theme in both modes). In any other shadcn app, the file replaces the theme blocks of your global CSS, after `@import "tailwindcss"`. Your draft is kept in this browser until you select **Reset**.

## Typography

Fonts, sizes, weights and line heights are tokens too: the `--typography-*` variables. Override them after the package import exactly like colors. See [Foundations › Typography](?path=/docs/foundations-typography--docs) for the catalog, every variable and how to install other fonts with Fontsource, or edit them visually in [Tools › Typography Builder](?path=/story/tools-typography-builder--default) (see the [Typography builder guide](?path=/docs/guides-typography-builder--docs)). The Theme Builder does not handle fonts or letter spacing.

## The customization ladder

When a token is not enough, go one step further, and only as far as you need:

1. **Tokens.** Change the CSS variables (above). Affects every component at once.
2. **`className`.** Every component merges your classes last (through `cn`), so `className="h-10 rounded-full"` wins over the defaults for one instance.
3. **Data attributes.** Components expose `data-slot`, `data-variant`, `data-size` and `data-state`; target them from CSS for a consistent change, e.g. `[data-slot="button"][data-variant="outline"] { … }`.
4. **Wrap.** Build your own component on top (`<SaveButton>` that renders `<Button>` with fixed props). In this repo those live in `packages/ui/src/components/`.
5. **Fork.** Copy the shadcn component into `src/components/` under a new name and change it. The files in `src/shadcn/` are owned by the shadcn CLI and must never be edited by hand.

## The Aureus brand theme

The package does not ship stock shadcn colors. `packages/ui/src/styles/theme.css` redefines every color token, in a `:root` block and then a `.dark` block, with the Aureus identity (see [Foundations › Colors](?path=/docs/foundations-colors--docs)):

| Role | Tokens | Light | Dark |
| --- | --- | --- | --- |
| Aureus Blue | `--primary`, `--ring`, `--sidebar-primary`, `--sidebar-ring` | `oklch(0.45 0.2 264)` | `oklch(0.62 0.17 264)`, with dark text |
| Aureus Gold | `--secondary` | `oklch(0.8 0.14 84)` | `oklch(0.82 0.13 86)` |
| Charts | `--chart-1` … `--chart-5` | blue, deep gold, light blue, bronze, slate | blue, gold, light blue, deep gold, slate |
| Neutrals | background, card, muted, accent, border, sidebar… | Tailwind slate | Tailwind slate |
| Accessible text | `--muted-foreground` slate-600, `--destructive` `oklch(0.51 0.2 27.325)` | 6.9:1 on `--muted`; 5.36:1 on its tint | `--destructive` `oklch(0.74 0.191 22.216)` |

Every text pair reaches 4.5:1 and the focus ring and charts 3:1, in both modes; the Theme Builder tests and the accessibility checks of every story verify it.

To change it, override tokens after the package import, light values in `:root` and dark values in `.dark` (or import a `theme.css` from the Theme Builder). To go back to stock shadcn colors, paste shadcn's own `:root` and `.dark` color blocks there. The `--brand-*` constants are not affected by those overrides.

# Temas

Todos los colores, radios, fuentes y tamaños de texto de los componentes vienen de propiedades personalizadas de CSS (tokens). Cambia los tokens y todos los componentes los siguen; nunca tienes que editar el código de un componente.

## Sustituye tokens en tu app

Añade tus valores **después** del import del paquete. Los valores claros van en `:root` y los oscuros en `.dark`:

```css
@import "@aureus-core/ui/styles.css";

:root {
  --primary: oklch(0.55 0.2 260);
  --primary-foreground: oklch(0.98 0 0);
  --radius: 0.5rem;
}

.dark {
  --primary: oklch(0.72 0.15 260);
  --primary-foreground: oklch(0.15 0 0);
}
```

Los tokens están listados, con muestras en vivo, en [Fundamentos › Colores](?path=/docs/foundations-colors--docs). Revisa el contraste cuando cambies una pareja (`--primary` / `--primary-foreground`, `--muted` / `--muted-foreground`…): el texto necesita 4.5:1 para WCAG AA.

## Creador de temas

En lugar de escribir los valores a mano, abre [Herramientas › Creador de temas](?path=/story/tools-theme-builder--default). Elige un color primario, una paleta neutra y un radio, sustituye cualquier token y mira cómo se actualizan en vivo los componentes reales y el contraste WCAG de cada pareja de texto, en modo claro y oscuro. También puedes pegar un tema que ya tengas (de ui.shadcn.com, tweakcn o una exportación anterior) para seguir editándolo.

- **Descargar .css** guarda un archivo de tema independiente (`:root`, `.dark` y `@theme inline`, todo en OKLCH) para cualquier app con shadcn y Tailwind CSS v4. No contiene fuentes ni espaciado entre letras: vienen del Creador de tipografía.
- **Copiar** pone el mismo contenido en el portapapeles.

El archivo se llama `theme.css` por defecto. En una app basada en este paquete, impórtalo después de `@import "@aureus-core/ui/styles.css"` (define cada token en sus bloques claro y oscuro, así que sustituye el tema de marca Aureus en los dos modos). En cualquier otra app con shadcn, el archivo sustituye los bloques del tema de tu CSS global, después de `@import "tailwindcss"`. Tu borrador se guarda en este navegador hasta que pulses **Restablecer**.

## Tipografía

Las fuentes, los tamaños, los pesos y los interlineados también son tokens: las variables `--typography-*`. Sustitúyelas después del import del paquete igual que los colores. Mira [Fundamentos › Tipografía](?path=/docs/foundations-typography--docs) para el catálogo, todas las variables y cómo instalar otras fuentes con Fontsource, o edítalas visualmente en [Herramientas › Creador de tipografía](?path=/story/tools-typography-builder--default) (mira la [guía del creador de tipografía](?path=/docs/guides-typography-builder--docs)). El Creador de temas no gestiona fuentes ni espaciado entre letras.

## La escalera de personalización

Cuando un token no basta, sube un peldaño, y solo hasta donde lo necesites:

1. **Tokens.** Cambia las variables CSS (arriba). Afecta a todos los componentes a la vez.
2. **`className`.** Todos los componentes aplican tus clases al final (con `cn`), así que `className="h-10 rounded-full"` gana a los valores por defecto en una instancia.
3. **Atributos data.** Los componentes exponen `data-slot`, `data-variant`, `data-size` y `data-state`; apúntalos desde CSS para un cambio coherente, p. ej. `[data-slot="button"][data-variant="outline"] { … }`.
4. **Envolver.** Construye tu propio componente encima (`<SaveButton>` que renderiza `<Button>` con props fijas). En este repo viven en `packages/ui/src/components/`.
5. **Bifurcar.** Copia el componente de shadcn a `src/components/` con otro nombre y cámbialo. Los archivos de `src/shadcn/` son del CLI de shadcn y nunca se editan a mano.

## El tema de marca Aureus

El paquete no usa los colores de serie de shadcn. `packages/ui/src/styles/theme.css` redefine todos los tokens de color, en un bloque `:root` y después un bloque `.dark`, con la identidad de Aureus (mira [Fundamentos › Colores](?path=/docs/foundations-colors--docs)):

| Rol | Tokens | Claro | Oscuro |
| --- | --- | --- | --- |
| Azul Aureus | `--primary`, `--ring`, `--sidebar-primary`, `--sidebar-ring` | `oklch(0.45 0.2 264)` | `oklch(0.62 0.17 264)`, con texto oscuro |
| Dorado Aureus | `--secondary` | `oklch(0.8 0.14 84)` | `oklch(0.82 0.13 86)` |
| Gráficos | `--chart-1` … `--chart-5` | azul, dorado profundo, azul claro, bronce, slate | azul, dorado, azul claro, dorado profundo, slate |
| Neutros | fondo, tarjetas, muted, accent, bordes, barra lateral… | slate de Tailwind | slate de Tailwind |
| Texto accesible | `--muted-foreground` slate-600, `--destructive` `oklch(0.51 0.2 27.325)` | 6.9:1 sobre `--muted`; 5.36:1 sobre su tinte | `--destructive` `oklch(0.74 0.191 22.216)` |

Todas las parejas de texto llegan a 4.5:1 y el anillo de foco y los gráficos a 3:1, en los dos modos; lo comprueban los tests del Creador de temas y las revisiones de accesibilidad de todas las stories.

Para cambiarlo, sustituye los tokens después del import del paquete, los valores claros en `:root` y los oscuros en `.dark` (o importa un `theme.css` del Creador de temas). Para volver a los colores de serie de shadcn, pega ahí los bloques de color `:root` y `.dark` del propio shadcn. Las constantes `--brand-*` no se ven afectadas por esos cambios.
